# gaboesquivel.com

Personal site — narrative pages, project and stack evidence, writing, CV, and contact. Project and technology facts come from the [`gaboesquivel`](https://github.com/gaboesquivel/gaboesquivel) npm package.

## Setup

```bash
bun install
bun run dev
```

Dev server: [http://localhost:3099](http://localhost:3099) (Velite + Next.js).

```bash
bun run verify          # content build + lint
bun run verify:routes   # route checks
```

Agent workflow and page rules: [AGENTS.md](AGENTS.md). Product and routes: [PRODUCT.md](PRODUCT.md). Visual system: [DESIGN.md](DESIGN.md).
